# Pantallas y navegación

| # | Pantalla | Ruta | Navegación principal |
|---|---|---|---|
| 1 | Login | `/login` | Entrar / invitado → Inicio; Crear cuenta → Registro |
| 2 | Registro | `/register` | Crear cuenta → Inicio; volver → Login |
| 3 | Inicio | `/home` | Buscar/categorías → Tienda; producto → Detalle |
| 4 | Tienda | `/store` | Producto → Detalle; Agregar → Carrito |
| 5 | Detalle | `/product/pergamino` | Agregar; Comprar ahora → Carrito |
| 6 | Carrito | `/cart` | Continuar compra → Dirección |
| 7 | Dirección | `/address` | Guardar y continuar → Entrega |
| 8 | Entrega | `/delivery` | Continuar → Pago |
| 9 | Pago | `/payment` | Continuar → Resumen |
| 10 | Resumen | `/order-summary` | Editar datos; Confirmar → Compra exitosa |
| 11 | Compra exitosa | `/order-success` | Ver pedido → Seguimiento; Seguir comprando → Inicio |
| 12 | Mis pedidos | `/orders` | Ver detalles → Seguimiento |
| 13 | Seguimiento | `/order-tracking` | Volver; barra inferior → Perfil/Inicio/Tienda/Carrito |
| 14 | Perfil | `/profile` | Mis pedidos / Direcciones / Métodos de pago / Cerrar sesión |
